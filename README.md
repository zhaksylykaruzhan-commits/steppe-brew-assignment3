# Steppe Brew - Responsive Web Design (Assignment 3)

Web Technologies 1, Astana IT University.

One responsive page about a coffee house, built in two ways:

- **Task 1 - media queries by hand:** the "Our services" section (`#services`). Own CSS only (Grid + Flexbox), mobile-first, breakpoints at 768px and 1100px. See `style.css`.
- **Task 2 - Bootstrap 5.3:** navbar, hero, about, menu cards, FAQ accordion, contact form, booking modal.
- **Task 3 - comparison:** see the report (`Assignment3_Ravil.docx`).

## Files
- `index.html` - the page (Bootstrap CDN links, viewport meta tag)
- `style.css` - my CSS, loaded after Bootstrap
- `screenshots/` - screenshots used in the report

## How to run
Open `index.html` in a browser (internet is needed for the Bootstrap CDN).
Use DevTools (F12) -> device toolbar to test 375px, 768px and 1280px.
